阶段四｜AI 辅助客户开发工具

用 Cloud Code 做了一个客户开发小工具，减少重复整理和写信的时间

做外贸客户开发时，我发现手动去 Google Maps 搜公司、打开网站、查找邮箱、整理客户信息，再一封封写开发信，整个过程比较重复，也比较耗时间。

所以我尝试用 Cloud Code 帮我做了一个简单的客户开发小工具。输入目标国家、行业关键词和开发数量后，它可以辅助搜索相关公司，整理公司名称、国家、网站、邮箱、电话、客户类型、状态、备注、来源页面和创建时间等信息。

整理完客户信息后，它还可以根据模板生成开发信，并进行邮件测试发送。这个工具目前还在测试和优化阶段，主要目的是帮助我提高客户开发和信息整理的效率。

这个工具目前做的事情

  • Google Maps 搜索
  • 客户信息整理
  • 开发信生成
  • 邮件测试发送
  • Cloud Code 实践
